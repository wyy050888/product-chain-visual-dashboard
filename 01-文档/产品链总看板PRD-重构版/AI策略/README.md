# AI策略 V1

首次开发交付，直接交付本目录即可。生产取数、模型调用和页面绑定由开发实现。

| 目录 | 看什么 |
| --- | --- |
| [01-策略](01-策略/) | 共用策略，以及总诊断、产品、店铺、部门根因四份专项策略。 |
| [02-提示词](02-提示词/) | 三份提示词合集：资料处理、诊断分析、跟进与复核。按目录跳转到需要的任务。 |
| [03-开发参考](03-开发参考/) | 开发接入说明（字段映射及返回约定）、指标口径、结果展示示例。 |

先看共用策略和自己负责的专项，再看接入说明与示例。提示词调用只提取所选章节的完整text代码块，填入实际资料，不把整份合集发送给模型。产品、店铺有原建议时，使用“跟进与复核”中的含原建议完整文本，替代基础诊断文本。

示例用于理解表达与样式，不作为生产默认值或模型预期答案。程序负责日期、部门拼接、来源名称、统计及样式，按既定字段、边界和异常处理要求完成接入。
