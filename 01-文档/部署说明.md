    node deploy/build.mjs
    npx wrangler@4.151.0 pages deploy dist --project-name chainboard-wyy --branch main

首次使用须先运行 npx wrangler@4.151.0 login 登录有 Pages 发布权限的账号，然后创建项目：

    npx wrangler@4.151.0 pages project create chainboard-wyy --production-branch main --force

--force 仅用于首次直接创建 Pages 项目，后续发布不需要。

当前页面是演示原型，没有共享数据库；页面偏好按浏览器分别保存，任务办理仅在当前页面有效，刷新恢复样例。

发布后的图片检查：

    node deploy/check-images.mjs https://chainboard-wyy.pages.dev/

该命令先逐个下载线上图片、核对发布包哈希并用浏览器解码，再检查实际页面图片是否有破图。默认重新检查全部资源；中途因网络中断时，可追加 --resume 只续查未完成项。
逐张结果保存在 outputs/image-audit/对应域名/report.json，可追溯每张图片的响应、尺寸、文件哈希和重试次数。
同站 assets 图片遇到加载错误会自动重试，最多两次，防止偶发传输失败后持续显示破图。
