# 产品链总看板原型

日常修改先看[维护指南.md](维护指南.md)，用 `node dev.mjs locate 关键词` 查当前入口，用 `node dev.mjs check filters` 或 `risk` 运行受影响范围。下方历史记录保留变更背景，当前实现以责任入口和源代码为准。

直接打开 `index.html`。页面、样例数据和交互来自原版 1006；不需要服务器或联网。

## 修改入口

- 页面框架：`src/page.html`
- 业务交互与样例数据：`src/modules/`，按业务划分文件夹
- 产品图片映射：`src/data/product-images.js`
- 图片文件：`assets/images/`
- 样式：`styles/`，编号顺序就是覆盖顺序
- 文件与函数定位：[模块索引.md](模块索引.md)
- 加载顺序：`manifest.json`

修改源文件后，双击 `构建.cmd`，或在本目录运行 `node build.mjs`。构建只更新 `index.html` 和 `assets/app.js`。已生成当前入口，可以直接汇报。

## 维护约束

原版包含大量共享变量和后续函数覆盖。本次按完整语句拆分，并保留同一作用域和执行顺序。各业务文件是源代码片段，构建后运行；不要分别用 script 标签加载。

`index.html`、`assets/app.js` 是生成文件，不直接修改，不作为日常阅读入口。原始 HTML 保留在上级目录。

这次是保持行为的文件拆分，未改造业务模型。新功能应在对应业务模块内实现；涉及跨模块的规则，先查索引和实际引用，不继续向公共文件堆积代码。样例数据仍是原版演示数据。

## 统一 SPU 产品详情（2026-10-12）
